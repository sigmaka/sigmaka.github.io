B.2.1 Glieder mit Ausgleich (P-Glieder)

HinweisReminder

P-Glieder weisen einen Beharrungszustand (stationären Zustand) auf, d. h. der Ausgang strebt für einen konstanten Eingang einen stationären Endwert an. Die Beziehung zwischen Ausgang und Eingang im Beharrungszustand wird durch die (statische) Kennlinie bzw. den Proportionalbeiwert K_P beschrieben.

P


x_a(t) = K_P \cdot x_e(t)

P-T1


\begin{aligned} T_1 \cdot \dot{x}_a(t) + x_a(t) \\ = K_P \cdot x_e(t) \end{aligned}

P-T2


\begin{aligned} T_1 \cdot T_2 \cdot \ddot{x}_a(t) \\ + (T_1+T_2) \cdot \dot{x}_a(t) \\ + x_a(t) \\ = K_P \cdot x_e(t) \end{aligned}

P-T2S


\begin{aligned} \frac{1}{\omega_0^2} \cdot \ddot{x}_a(t) \\ + 2 \cdot \frac{D}{\omega_0} \cdot \dot{x}_a(t) \\ + x_a(t) \\ = K_P \cdot x_e(t) \end{aligned}

P-Tn


\ldots

P-Tt


x_a(t) = K_P \cdot x_e(t - T_t)

stepData = {
  const K = 1;
  const dt = 0.01;
  const tMax = 10;
  const data = [];

  for (let t = 0; t <= tMax + Tt; t += dt) {
    let y = 0;

    if (t >= Tt) {
      const tau = t - Tt;

      if (systemType === "ns") {
        if (Math.abs(T1 - T2) < 1e-6 && T1 > 1e-6) {
          y = K * (1 - (1 + tau / T1) * Math.exp(-tau / T1));
        } else if (T1 > 1e-6 && T2 > 1e-6) {
          const a = T1 / (T1 - T2);
          const b = T2 / (T1 - T2);
          y = K * (1 - a * Math.exp(-tau / T1) + b * Math.exp(-tau / T2));
        } else if (T1 > 1e-6) {
          y = K * (1 - Math.exp(-tau / T1));
        } else if (T2 > 1e-6) {
          y = K * (1 - Math.exp(-tau / T2));
        } else {
          y = K;
        }
      } else if (systemType === "os") {
        const w = omega;
        const d = Damp;
        if (d < 1) {
          const wd = w * Math.sqrt(1 - d * d);
          const phi = Math.acos(d);
          y = K * (1 - Math.exp(-d * w * tau) / Math.sqrt(1 - d * d) * Math.sin(wd * tau + phi));
        } else {
          y = K * (1 - (1 + w * tau) * Math.exp(-w * tau));
        }
      }
    }

    if (t <= tMax) {
      data.push({t, y});
    }
  }

  return data;
}

B.2.2 Glieder ohne Ausgleich (I-Glieder)

HinweisReminder

I-Glieder weisen keinen Beharrungszustand (keinen stationären Zustand) auf, d. h. es gibt keine (statische) Kennlinie und damit keinen Proportionalbeiwert K_P​.

I-Glieder beschreiben wir mit dem Integrierbeiwert K_I​ bzw. alternativ mit der Integrierzeit T_I, wobei die eine Grösse die Inverse der andern ist (K_I=1/T_I​).

I


\dot{x}_a(t) = K_I \cdot x_e(t)

I-T1


\begin{aligned} T_1 \cdot \ddot{x}_a(t) \\ + \dot{x}_a(t) \\ = K_I \cdot x_e(t) \end{aligned}

\ldots

\ldots

\ldots

I-Tt


\begin{aligned} \dot{x}_a(t) \\ = K_I \cdot x_e(t - T_t) \end{aligned}

B.2.3 D-Glieder

Neben dem P-Glied (proportional), dem I-Glied (integrierend) kommt in Reglern auch das D-Glied (differenzierend) zur Anwendung.

HinweisD-Glieder

D-Glieder wirken differenzierend (daher der Name), d. h. sie wirken auf die Ableitung des Eingangssignals (d. h. für eine konstante Eingangsgrösse ist die Ausgangsgrösse null).

D-Glieder werden mit dem Differenzierbeiwert K_D​ bzw. alternativ mit der Differenzierzeit T_D beschrieben, wobei K_D = T_D gilt.

Das ideale D-Glied existiert in der Praxis nicht, d. h. ein reales D-Glied wird immer mit einer zusätzlichen Verzögerung, also als D-T1 implementiert.

D


x_a(t) = K_D \cdot \dot{x}_e(t)

D-T1


\begin{aligned} T_1 \cdot \dot{x}_a(t) \\ + x_a(t) \\ = K_D \cdot \dot{x}_e(t) \end{aligned}

B.2.4 Regelglieder

Werden P-, I- und D-Glied parallelgeschaltet, entstehen das PI-, das PD- und das PID-Glied.

HinweisPD/PID-T1

Wenn der Regler einen D-Anteil enthält (PD bzw. PID), wird der D-Anteil immer mit einer zusätzlichen (kleinen) Verzögerung T_{\mathrm{Vz}} implementiert (ein reines D-Glied ist nicht realisierbar). Der Regler wird dann PD-T1 bzw. PID-T1 genannt oder einfach realer PD/PID-Regler. Der Effekt der Verzögerungszeit ist in der jeweiligen Sprungantwort ersichtlich, beim Icon und der Reglergleichung verwenden wir der Einfachheit halber jeweils die ideale Darstellung.

P-Regler

siehe P-Glied oben

I-Regler

siehe I-Glied oben

PI-Regler

\begin{aligned} y(t) = K_P \cdot \Bigl( &e(t) \\ &+ \frac{1}{T_i} \cdot \int{e(t) \, \mathrm{d}t} \Bigr) \end{aligned}

PD-Regler

\begin{aligned} y(t) = K_P \cdot \Bigl( &e(t) \\ &+ T_d \cdot \dot{e}(t) \Bigr) \end{aligned}

PID-Regler

\begin{aligned} y(t) = K_P \cdot \Bigl( &e(t) \\ &+ \frac{1}{T_i} \cdot \int{e(t) \, \mathrm{d}t} \\ &+ T_d \cdot \dot{e}(t) \Bigr) \end{aligned}

//| echo: false
stepData = {
  const K = 1;
  const dt = 0.01;
  const tMax = 10;
  const data = [];

  for (let t = 0; t <= tMax + Tt; t += dt) {
    let y = 0;

    if (t >= Tt) {
      const tau = t - Tt;

      if (systemType === "ns") {
        if (Math.abs(T1 - T2) < 1e-6 && T1 > 1e-6) {
          y = K * (1 - (1 + tau / T1) * Math.exp(-tau / T1));
        } else if (T1 > 1e-6 && T2 > 1e-6) {
          const a = T1 / (T1 - T2);
          const b = T2 / (T1 - T2);
          y = K * (1 - a * Math.exp(-tau / T1) + b * Math.exp(-tau / T2));
        } else if (T1 > 1e-6) {
          y = K * (1 - Math.exp(-tau / T1));
        } else if (T2 > 1e-6) {
          y = K * (1 - Math.exp(-tau / T2));
        } else {
          y = K;
        }
      } else if (systemType === "os") {
        const w = omega;
        const d = Damp;
        if (d < 1) {
          const wd = w * Math.sqrt(1 - d * d);
          const phi = Math.acos(d);
          y = K * (1 - Math.exp(-d * w * tau) / Math.sqrt(1 - d * d) * Math.sin(wd * tau + phi));
        } else {
          y = K * (1 - (1 + w * tau) * Math.exp(-w * tau));
        }
      }
    }

    if (t <= tMax) {
      data.push({t, y});
    }
  }

  return data;
}

### D-Glieder

Neben dem P-Glied (*proportional*), dem I-Glied (*integrierend*) kommt in Reglern auch das D-Glied (*differenzierend*) zur Anwendung.

::: {.callout-note title="D-Glieder"}

D-Glieder wirken *differenzierend* (daher der Name), d. h. sie wirken auf die Ableitung des Eingangssignals (d. h. für eine konstante Eingangsgrösse ist die Ausgangsgrösse null).

D-Glieder werden mit dem Differenzierbeiwert $K_D$​ bzw. alternativ mit der Differenzierzeit $T_D$ beschrieben, wobei $K_D = T_D$ gilt.

Das *ideale* D-Glied existiert in der Praxis nicht, d. h. ein *reales* D-Glied wird immer mit einer zusätzlichen Verzögerung, also als D-T~1~ implementiert.

### Regelglieder

Werden P-, I- und D-Glied parallelgeschaltet, entstehen das PI-, das PD- und das PID-Glied.

::: {.callout-note title="PD/PID-T~1~"}

Wenn der Regler einen D-Anteil enthält (PD bzw. PID), wird der D-Anteil immer mit einer zusätzlichen (kleinen) Verzögerung $T_{\mathrm{Vz}}$ implementiert (ein reines D-Glied ist nicht realisierbar). Der Regler wird dann PD-T~1~ bzw. PID-T~1~ genannt oder einfach *realer* PD/PID-Regler. Der Effekt der Verzögerungszeit ist in der jeweiligen Sprungantwort ersichtlich, beim Icon und der Reglergleichung verwenden wir der Einfachheit halber jeweils die *ideale* Darstellung.
