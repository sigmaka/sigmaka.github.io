B.2.1 Glieder mit Ausgleich (P-Glieder)

HinweisReminder

P-Glieder weisen einen Beharrungszustand (stationären Zustand) auf, d. h. der Ausgang strebt für einen konstanten Eingang einen stationären Endwert an. Die Beziehung zwischen Ausgang und Eingang im Beharrungszustand wird durch die (statische) Kennlinie bzw. den Proportionalbeiwert K_P beschrieben.

P


x_a(t) = K_P \cdot x_e(t)

P-T1


\begin{aligned} T_1 \cdot \dot{x}_a(t) + x_a(t) \\ = K_P \cdot x_e(t) \end{aligned}

P-T2


\begin{aligned} T_1 \cdot T_2 \cdot \ddot{x}_a(t) \\ + (T_1+T_2) \cdot \dot{x}_a(t) \\ + x_a(t) \\ = K_P \cdot x_e(t) \end{aligned}

P-T2S


\begin{aligned} \frac{1}{\omega_0^2} \cdot \ddot{x}_a(t) \\ + 2 \cdot \frac{D}{\omega_0} \cdot \dot{x}_a(t) \\ + x_a(t) \\ = K_P \cdot x_e(t) \end{aligned}

P-Tn


\ldots

P-Tt


x_a(t) = K_P \cdot x_e(t - T_t)

B.2.1.1 Interaktive Sprungantwort

Ändere die Parameter im untenstehenden Sprungantwort-Simulator und betrachte den Effekt auf die Sprungantwort. Die Sprungantwort wird jeweils für einen Einheitssprung am Eingang und K_P = 1 angezeigt. Für K_P gibt es keinen Slider, dieser würde lediglich die Höhe der Sprungantwort verändern.

stepData = {
  const K = 1;
  const dt = 0.01;
  const tMax = 10;
  const data = [];

  for (let t = 0; t <= tMax + Tt; t += dt) {
    let y = 0;

    if (t >= Tt) {
      const tau = t - Tt;

      if (systemType === "ns") {
        if (Math.abs(T1 - T2) < 1e-6 && T1 > 1e-6) {
          y = K * (1 - (1 + tau / T1) * Math.exp(-tau / T1));
        } else if (T1 > 1e-6 && T2 > 1e-6) {
          const a = T1 / (T1 - T2);
          const b = T2 / (T1 - T2);
          y = K * (1 - a * Math.exp(-tau / T1) + b * Math.exp(-tau / T2));
        } else if (T1 > 1e-6) {
          y = K * (1 - Math.exp(-tau / T1));
        } else if (T2 > 1e-6) {
          y = K * (1 - Math.exp(-tau / T2));
        } else {
          y = K;
        }
      } else if (systemType === "os") {
        const w = omega;
        const d = Damp;
        if (d < 1) {
          const wd = w * Math.sqrt(1 - d * d);
          const phi = Math.acos(d);
          y = K * (1 - Math.exp(-d * w * tau) / Math.sqrt(1 - d * d) * Math.sin(wd * tau + phi));
        } else {
          y = K * (1 - (1 + w * tau) * Math.exp(-w * tau));
        }
      }
    }

    if (t <= tMax) {
      data.push({t, y});
    }
  }

  return data;
}

B.2.2 Glieder ohne Ausgleich (I-Glieder)

HinweisReminder

I-Glieder weisen keinen Beharrungszustand (keinen stationären Zustand) auf, d. h. es gibt keine (statische) Kennlinie und damit keinen Proportionalbeiwert K_P​.

I-Glieder beschreiben wir mit dem Integrierbeiwert K_I​ bzw. alternativ mit der Integrierzeit T_I, wobei die eine Grösse die Inverse der andern ist (K_I=1/T_I​).

I


\dot{x}_a(t) = K_I \cdot x_e(t)

I-T1


\begin{aligned} T_1 \cdot \ddot{x}_a(t) \\ + \dot{x}_a(t) \\ = K_I \cdot x_e(t) \end{aligned}

\ldots

\ldots

\ldots

I-Tt


\begin{aligned} \dot{x}_a(t) \\ = K_I \cdot x_e(t - T_t) \end{aligned}

//| echo: false
stepData2 = {
  const dt = 0.01;
  const tMax = 10;
  const data = [];

  for (let t = 0; t <= tMax + Ttval; t += dt) {
    let y = 0;

    if (t >= Ttval) {
      const tau = t - Ttval;

      if (T1val > 1e-6) {
        y = KIval * (tau - T1val + T1val * Math.exp(-tau / T1val));
      } else {
        y = KIval * tau;
      }
    }

    if (t <= tMax) {
      data.push({t, y});
    }
  }

  return data;
}
