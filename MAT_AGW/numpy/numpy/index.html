NumPy (Numerical Python) ist eine mächtige Bibliothek für numerische Berechnungen im technisch-wissenschaftlichen Umfeld und bildet die Basis für viele weitere Pakete des Python-Ökosystems. Als wesentliche Erweiterungen von NumPy gegenüber Basis-Python können genannt werden:

  • leistungsfähiger Array-Datentyp für ein- bzw. mehrdimensionale Datenobjekte

  • leistungsfähige Algorithmen für mehrdimensionale Arrayobjekte

  • umfangreiche Sammlung mathematischer Funktionen

Wir werden NumPy schrittweise kennenlernen und über das gesamte Modul hinweg intensiv einsetzen, wobei nach und nach weitere Bibliotheken dazustossen.

1. Motivation¶

Die grundlegenden Python-Datentypen (list, tuple, dict) eignen sich nicht für mathematische Berechnungen. NumPy bringt mit dem NumPy-Array (ndarray) einen sehr nützlichen Datentyp mit sich, der effiziente Berechnungen (auch grosser Datenmengen) ermöglicht.

☝🏼 Überlege dir übungshalber kurz, wie du alle Elemente einer Liste my_list = [1, 2, 3] z. B. quadrieren würdest. Wäre z. B. my_list**2 möglich? Probier es aus.

1.1 Import¶

NumPy (Paketname numpy) wird üblicherweise mit dem Alias np importiert. Du solltest NumPy bereits installiert haben, ansonsten kannst du es mit pip install numpy via Terminal (→ JupyterLab Launcher → Terminal) oder mit ! pip install numpy direkt im Notebook installieren.

import numpy as np

2. Array (ndarray)¶

Der ndarray (nachfolgend einfach Array genannt) ist die zentrale Datenstruktur der NumPy-Bibliothek und kann ein-, zwei- oder auch höherdimensional sein. Da der Array viele Ähnlichkeiten mit der Liste aufweist, können wir bzgl. Erstellung und Indizierung auf das vorhandene Wissen aufbauen.

☝🏼 Einen eindimensionalen Array (1D-Array) sollte man sich ohne Orientierung (also nicht als Zeile oder Spalte) vorstellen, sondern einfach als Anordnung von Elementen (wie eine Liste).

a = np.array([-1.23, 0, 2.5])  # manuelle Erstellung eines Arrays
print(a)
type(a)
[-1.23  0.    2.5 ]
numpy.ndarray

☝🏼 Es fällt auf, dass die Ausgabe eines Arrays am Bildschirm (siehe oben bei print(a)) gleich aussieht wie bei einer Liste. Arrays und Listen haben viele Ähnlichkeiten, doch es ist wichtig, dass du dir immer im Klaren über den Datentyp bist. Im Zweifelsfall hilft die bekannte Funktion type(), um den Datentyp zu bestimmen.

2.1 Erstellung¶

Für die Erstellung von 1D-Arrays wird meistens eine der folgenden Funktionen verwendet:

  • np.array() - für die manuelle Erzeugung (oder Konversion von einem anderen Datentyp)

  • np.arange() - analog zur Funktion range(), aber nicht auf Ganzzahlen beschränkt

  • np.linspace() - wie np.arange(), aber mit Sampleanzahl anstelle der Schrittweite

  • np.logspace() - wie np.linspace(), aber mit logarithmischer Teilung

a = np.array([-1, 0, 1, 2])  # manuell, ähnlich zur Erstellung einer Liste
print(a)
a = np.arange(0, 1, step=0.2) # (Startwert, Endwert (nicht inkl.), Schrittweite)
print(a)
a = np.linspace(0, 5, num=9)  # (Startwert, Endwert (inkl.), Sampleanzahl)
print(a)
a = np.linspace(0, 5, num=9, endpoint=False)  # wie oben, aber diesmal Endwert nicht inkl.
print(a)
a = np.logspace(-2, 3, num=6, base=10.0)  # logarithmische Teilung
print(a)

B. zwei Achsen, d. h. eine bestimmte Anzahl Zeilen und eine bestimmte Anzahl Spalten. Ein Array ist immer rechteckig/quadratisch, d. h. die Anzahl der Spalten ist in jeder Zeile gleich (und umgekehrt).

Für das Erstellen von Arrays mit Nullen bzw. Einsen oder Zufallszahlen gibt es ebenfalls nützliche Funktionen. Daneben gibt es eine Reihe von Funktionen, welche man im Zusammenhang mit der linearen Algebra (Vektor- bzw. Matrizenrechnung) häufig benötigt.

  • np.zeros() bzw. np.ones() - für die Erstellung eines Arrays mit 0 bzw. 1

2.1.1 Import/Export von Textdateien¶

Zweidimensionale Arrays werden häufig im Zusammenhang mit eingelesenen Daten (Textfiles, Bilder, etc.) verwendet und eher selten manuell erstellt. Für das Arbeiten mit Textdateien (.txt, .csv) sind die folgenden beiden Funktionen zu erwähnen:

  • np.loadtxt() - Einlesen einer Textdatei

  • np.savetxt() - Abspeichern in eine Textdatei

Wie immer beim Einlesen von Textdateien ist darauf zu achten, ob Headerzeilen vorhanden sind, die ignoriert werden müssen und welches Zeichen als Trennzeichen verwendet wird (bei mehreren Spalten). Die obigen Funktionen enthalten dafür entsprechende Parameter (skiprows bzw. delimiter).

2.2 Array-Attribute¶

Der NumPy-Array kommt mit vielen Attributen, welche nützlich sind, um z. B. Dimension, Grösse, Datentyp etc. abfragen zu können.

  • .ndim - Dimension des Arrays

  • .shape - Form/Grösse, d.h. Anzahl Zeilen & Spalten etc.

  • .size - Gesamtanzahl Elemente

  • .dtype - Element-Datentyp

  • .real bzw. .imag - Real- bzw. Imaginärteil bei komplexen Zahlen

☝🏼 Die Python-Funktion len() gibt bei Arrays jeweils die Länge der ersten Dimension (z. B. Anzahl Zeilen bei 2D-Array) zurück. Besonders bei höherdimensionalen Arrays bzw. wenn sich die Arraydimensionen verändern, wird deshalb besser mit .shape gearbeitet.

☝🏼 Im Gegensatz zu Listen kann ein Array nicht verschiedene Datentypen enthalten. Alle Elemente eines Arrays haben denselben Datentyp (int/float/complex).

print(a.ndim)  # Array-Dimension
print(a.shape)  # Array-Shape (Anzahl Zeilen/Spalten etc.)
print(a.size)  # Anzahl Elemente (gesamthaft)
print(a.dtype)  # Element-Datentyp

2.3 Array-Methoden¶

Neben den oben erwähnten Attributen bietet der NumPy-Array viele nützliche Operationen direkt als Methoden an, was eine elegante/übersichtliche Programmierung ermöglicht.

Nützliche Methoden:

  • .max() bzw. .min() - Maximum bzw. Minimum des Arrays

  • .argmax() bzw..argmin() - Index des Maximums bzw. Minimums

  • .mean(), .std(), .var() - Mittelwert, Standardabweichung, Varianz

  • .sum() bzw. .cumsum() - Summe bzw. kumulierte Summe

  • .prod() bzw. .cumprod() - Produkt bzw. kumuliertes Produkt

  • .round() - Runden

  • .sort() - Sortierung

  • .transpose() - Transponierung (vgl. Vektorrechnung)

Viele der obigen Methoden existieren auch als allg. Funktionen in NumPy. Das Maximum eines Arrays kann z. B. entweder via Methode a.max() oder via Funktion np.max(a) bestimmt werden.

☝🏼 Bei Funktionen wie z. B. .sum() oder .max(), bei denen die Anwendung auf einen höherdimensionalen Array nicht eindeutig ist, kann mit dem Parameter axis angegeben werden, ob die Operation zeilen- bzw. spaltenweise durchgeführt werden soll oder auf den gesamten Array angewendet werden soll.

  • axis = 0 - pro Spalte (z. B. Spaltensummen)

  • axis = 1 - pro Zeile (z. B. Zeilensummen)

  • axis = None - über alle Elemente (Default)

print(a.mean())  # Mittelwert aller Elemente
print(a.sum())  # Summe aller Elemente
print(a.sum(axis=0))  # Spaltensummen
print(a.sum(axis=1))  # Zeilensummen

3. Form/Gestalt eines Arrays¶

Sehr wichtig im Zusammenhang mit Arrays (besonders mit höherdimensionalen) ist, dass man sich immer im Klaren über die Dimension und die Form/Gestalt (shape) des Arrays ist, da das Debugging sonst mühsam werden kann. Dies ist v. a. in Bezug auf die Indizierung sehr wichtig. Wir werden primär mit 1D- und 2D-Arrays zu tun haben, es sind aber auch drei- und höherdimensionale Arrays möglich.

3.1 Formänderung¶

Die Array-Methode .reshape() ermöglicht es, die Dimension eines Arrays zu ändern, also z. B. einen 1D-Array mit 6 Elementen in einen 2D-Array mit z. B. 2 Zeilen & 3 Spalten zu verwandeln.

a = np.arange(3, 0, -0.25)  # 1D-Array mit 12 Elementen
print(a)
b = a.reshape((3,4))  # 2D-Array mit 3 Zeilen und 4 Spalten (= 12 Elemente)
print(b)
[3.   2.75 2.5  2.25 2.   1.75 1.5  1.25 1.   0.75 0.5  0.25]
[[3.   2.75 2.5  2.25]
 [2.   1.75 1.5  1.25]
 [1.   0.75 0.5  0.25]]

3.2 Indizierung und Slicing¶

Wie bei Listen erfolgt das Indizieren/Slicing mit [].

# 1D-Array
print(a[0])  # erstes Element (Index 0)
print(a[-1])  # letztes Element
print(a[4:9])  # Slicing
3.0
0.25
[2.   1.75 1.5  1.25 1.  ]

Für höherdimensionale Arrays ist die Indizierung bedeutend intuitiver als bei Listen, da nicht mehrere Klammern verwendet werden müssen, sondern die Indizes mit , getrennt werden können.

# 2D-Array
print(b[0,0])  # Element in erster Zeile / erster Spalte
print(b[1,:])  # alle Elemente der zweiten Zeile (alternativ b[1])
print(b[:,2])  # alle Elemente der dritten Spalte
3.0
[2.   1.75 1.5  1.25]
[2.5 1.5 0.5]

Besonders erwähnenswert im Zusammenhang mit der Indizierung ist die boolesche Indizierung (boolean indexing), die sehr praktisch ist, um einen Array anhand seiner Elemente (Werte) zu “filtern”, d. h. nur bestimmte Elemente zu identifizieren.

print(a[a>2])  # alle Elemente aus a, die grösser als 2 sind
print(a[(a>1)&(a<2)])  # alle Elemente aus a, die grösser als 1 und kleiner als 2 sind
a[(a>=2.5)|(a<=0.5)] = 0  # alle Elemente aus a, die grösser/gleich 2.5 oder kleiner/gleich 0.5 sind auf 0 setzen
print(a)
[3.   2.75 2.5  2.25]
[1.75 1.5  1.25]
[0.   0.   0.   2.25 2.   1.75 1.5  1.25 1.   0.75 0.   0.  ]

Dies wird boolesche Indizierung genannt, weil in den []-Klammern dabei ein boolescher Array steht, der für jedes Element entweder True oder False ist.

print(a>1)  # Vergleiche führen zu booleschem Array
[False False False  True  True  True  True  True False False False False]

print(a[a>1])  # Indizierung mit booleschem Array (siehe auch Bsp. oben)
[2.25 2.   1.75 1.5  1.25]

3.3 Editieren/Kopieren¶

Elemente in Arrays können verändert werden, wie wir dies von Listen kennen. Wie bei Listen muss beachtet werden, dass eine Zuweisung eines Arrays a zur Variable b, also b = a, keine Kopie aller Arrayelemente vornimmt, sondern lediglich die Referenz auf den Array kopiert. Der Array b “enthält” dann dieselben Elemente wie a und wenn ein Element in b verändert wird, so zeigt sich diese Änderung auch in a.

a = np.array([1, 2, 3])
b = a  # keine Kopie, nur Zuweisung (Referenz)
b[1] = -99  # auch a wird verändert
print('a: ', a)
print('b: ', b)
a:  [  1 -99   3]
b:  [  1 -99   3]

Eine wirkliche (eigenständige) Kopie kann mit der Methode .copy() erzeugt werden.

a = np.array([1, 2, 3])
b = a.copy()  # Kopie
b[1] = -99  # a ist nicht betroffen
print('a: ', a)
print('b: ', b)
a:  [1 2 3]
b:  [  1 -99   3]

NumPy bringt ebenfalls alle relevanten Konstanten und mathematischen Funktionen mit sich, die man für technische/mathematische Berechnungen benötigt. Der Import des math-Moduls ist somit nicht nötig, wenn mit NumPy gearbeitet wird.

Nützliche Konstanten:

  • np.pi - Kreiszahl π\piπ

  • np.e - Eulersche Zahl eee

  • np.inf - unendlich, z. B. bei Division durch 0

  • np.nan - undefiniert, not a number

4.2 Funktionen¶

Eine Auswahl von nützlichen mathematischen Funktionen, die (hoffentlich :-) selbsterklärend sind:

  • np.arcsin(), np.arccos(), np.arctan() bzw. np.arctan2() - inverse Winkelfunktionen

  • np.exp() - Exponentialfunktion

Nützliche Umrechnungsfunktionen bzw. Hilfsfunktionen:

A. Anhang¶

Hier folgen weiterführende Informationen zum NumPy-Array, die wir allerdings im Unterricht nicht benötigen und daher als optional zu betrachten sind.

A.1 Elementdatentyp¶

Da NumPy für maximale Performance entwickelt wurde, unterscheidet sich der Array dahingehend von der Liste, dass sämtliche Elemente im Array denselben Datentyp aufweisen. Dieser Elementdatentyp kann optional bei der Erstellung zugewiesen werden und es steht eine Reihe von spezifischen Datentypen zur Verfügung, wobei die Zahl jeweils für die entsprechende Bitgrösse steht:

  • np.uint8/16/32/64 - vorzeichenlose Ganzzahlen (unsigned integer)

  • np.int8/16/32/64 - vorzeichenbehaftete Ganzzahlen (signed integer)

  • np.float16/32/64/96/128 - Gleitkommazahlen (floating point)

  • np.complex64/128/192/256 - komplexe Zahlen (complex)

Dies ermöglicht es, für eine bestimmte Anwendung den optimalen (in Bezug auf den Speicherplatz kleinstmöglichen) Datentyp zu wählen.

☝🏼 Der Elementdatentyp uint16 beinhaltet z. B. nur vorzeichenlose (u steht für unsigned) Ganzzahlen (also nur positive, ganze Zahlen) und weist 216 verschiedene Zahlen auf. Da die 0 eingeschlossen ist, ist der Wertebereich auf 0…216−10 \dots 2^{16}-10…216−1 also 0…655350 \dots 655350…65535 beschränkt. Der Elementdatentyp int16 dagegen beinhaltet auch negative Ganzzahlen und enthält ebenfalls 216 verschiedene Zahlen. Der Wertebereich beträgt dann −2162…2162−1-\frac{2^{16}}{2} \dots \frac{2^{16}}{2}-1−2216​…2216​−1 also −32768…0…32767-32768 \dots 0 \dots 32767−32768…0…32767.

a = np.array([[-1, 0, 1, 2],
              [0, 1, 3, 1]], dtype=np.float32)  # explizite Datentyp-Zuweisung
print(a, a.dtype)
[[-1.  0.  1.  2.]
 [ 0.  1.  3.  1.]] float32

Der Datentyp kann mit der Methode .astype() geändert werden.

b = a.astype(np.int8)  # Datentyp-Umwandlung
print(b, b.dtype)
[[-1  0  1  2]
 [ 0  1  3  1]] int8

Wird der Datentyp nicht explizit angegeben, wählt NumPy automatisch einen passenden Datentyp. Wir werden in der Regel so arbeiten und uns daher i. Allg. nicht mit dem Elementdatentyp beschäftigen.

a = np.array([-1, 0, 1, 2])  # automatische Datentyp-Zuweisung (Ganzzahl)
print(a, a.dtype)
a = np.array([0.1, 1, 10])  # automatische Datentyp-Zuweisung (Gleitkommazahl)
print(a, a.dtype)
[-1  0  1  2] int64
[ 0.1  1.  10. ] float64
