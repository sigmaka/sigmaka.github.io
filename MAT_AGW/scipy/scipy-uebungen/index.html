# Imports

Übung 1¶

In vielen technischen Anwendungen hat man es mit verrauschten Signalen zu tun, die für die weitere Verarbeitung gefiltert/geglättet werden müssen. In diesem Beispiel geht es um ein solches verrauschtes Messsignal, das im Textfile Rauschsignal abgelegt ist.

a) Textfile einlesen und darstellen¶

  • Lese die Textdatei Rauschsignal aus dem Ordner data ein. In der ersten Spalte ist der Zeitarray t [s] und in der zweiten Spalte das Messignal y [mA].

  • Stelle das Signal grafisch dar, um den Verlauf beurteilen zu können.

# Code

b) Signal filtern/glätten¶

  • Glätte das Signal mit einem Savitzky-Golay-Filter (signal.savgol_filter()), wobei eine Fensterlänge window_length von 1000 und ein Polynomgrad polyorder von 3 verwendet werden soll.

# Code

c) Darstellung¶

  • Stelle das Rohsignal (kleine, blaue Punkte) zusammen mit dem geglätteten Signal (dicke, rote Linie) über der Zeit grafisch dar (inkl. Legende und Achsenbeschriftungen).

Übung 2¶

In dieser Aufgabe wird ein Signal “heruntergesampelt”, d. h. nachträglich mit einer tieferen Abtastfrequenz abgetastet. Davor wird ein allfälliger Trend aus dem Signal entfernt.

a) Textfile einlesen und darstellen¶

  • Lese die Textdatei Gausspuls.txt aus dem Ordner data ein. Das Signal wurde mit einem Abtastintervall von Δt=0.1 ms\Delta t = 0.1\,\text{ms}Δt=0.1ms abgetastet.

  • Stelle das Signal in einem Diagramm dar.

# Code

b) Trend entfernen¶

  • Entferne den Trend des Signals mit der SciPy-Funktion signal.detrend() und stelle das resultierende Signal zusammen mit dem Originalsignal grafisch dar.

☝🏼 Als Trend oder Drift wird eine langsame Veränderung des Signals bezeichnet (sozusagen das Gegenteil von hochfrequenten Schwingungen/Rauschen etc.). Langsame Veränderungen entsprechen tiefen Frequenzen, d. h. ein Trend könnte alternativ z. B. mit einem Hochpassfilter entfernt werden.

# Code

c) Downsampling¶

  • Um die Datenmenge bzw. die Anzahl Samples des Signals zu reduzieren, stehen Downsampling/Resampling-Funktionen zur Verfügung. Verwende die SciPy-Funktion signal.decimate(), um die Sampleanzahl um den Faktor 500 zu reduzieren, d. h. nur noch jeden 500. Sample zu “behalten”.

  • Stelle das Signal aus b) in blau zusammen mit dem “heruntergesampelten” Signal im gleichen Diagramm dar, wobei das “heruntergesampelte” Signal mit roten Kreuzen (ohne Linie) dargestellt werden soll.
